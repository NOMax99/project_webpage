# Komponenten

Dieser Ordner ist für wiederverwendbare HTML-Komponenten reserviert.

## Zweck

Wiederverwendbare Komponenten ermöglichen es, Code zu teilen und die Wartbarkeit zu verbessern.

## Beispiele für mögliche Komponenten:

### 1. Header Komponente
Die Navigation ist bereits eine Komponente in `index.html` und kann in andere Seiten kopiert werden.

### 2. Footer Komponente
Der Footer ist ebenfalls eine wiederverwendbare Komponente.

### 3. News Card Komponente
Wird dynamisch durch JavaScript generiert (siehe `js/newsLoader.js`).

### 4. Zukünftige Komponenten

Sie können hier weitere Komponenten erstellen, z.B.:
- Kontaktformulare
- Bildergalerien
- Testimonials
- Call-to-Action Buttons

## Verwendung

Um eine neue Komponente zu erstellen:

1. Erstellen Sie eine neue HTML-Datei in diesem Ordner
2. Definieren Sie die Struktur der Komponente
3. Fügen Sie entsprechendes CSS in `css/style.css` hinzu
4. Integrieren Sie die Komponente in Ihre Seiten

Alternativ können Sie JavaScript verwenden, um Komponenten dynamisch zu laden und einzufügen.
